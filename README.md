# The Trust Lab

A calibration and disagreement arena for AI models: **do models know when they are guessing, and does disagreement between models predict errors better than stated confidence?**

Status: Stage 0 + Stage 1 scaffold complete. All scoring is plain code — never an AI judge. Run offline with `--dry-run` to verify before adding API keys.

## Design notes

- **Answer format:** multiple choice, yes/no, or numeric-with-tolerance. Free-text is not graded (no AI judge).
- **Confidence:** models reply with their answer, then `Confidence: <0-100>`. Parsed with regex.
- **Post-cutoff questions:** correct behavior is low confidence or abstaining — a test of whether a model knows it's guessing.
- **Caching + resume:** every call is cached to `cache/` and logged to `logs/calls.jsonl`. Re-runs skip cached calls.
- **Plain-code scoring:** Brier score, calibration gap (avg confidence − accuracy), and abstain rate — all verifiable by hand.
